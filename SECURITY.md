# Security policy

Please do not open a public issue for security problems.

Report vulnerabilities privately via GitHub's **Security → Report a vulnerability**
advisory flow for this repository, or email `security@halalstockengine.app`.

Include:

- affected component (web, mobile, Edge Function, SQL/RLS)
- reproduction steps or a proof of concept
- impact assessment
- suggested remediation, if known

We aim to acknowledge within 48 hours and to ship a fix or mitigation within 7 days
for critical issues. Please give us reasonable time before public disclosure.

The full threat model, RLS matrix and hardening checklist are in
[`docs/SECURITY.md`](./docs/SECURITY.md).
